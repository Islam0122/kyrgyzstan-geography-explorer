# Kyrgyzstan Geography Explorer

Интерактивный цифровой атлас и учебная платформа «География Кыргызской Республики» (RU / KG).

**Стек:** React 19 · TypeScript · Vite · Tailwind CSS 4 · Framer Motion · React Router · Zustand · Leaflet · Three.js · Recharts · Lucide React.
Frontend-only, прогресс хранится в `localStorage`.

```bash
cd geo-explorer
npm install
npm run dev        # разработка
npm run build      # сборка в dist/ (любой статический хостинг; HashRouter)
npm run preview
```

## Данные — что откуда (без выдуманных цифр)

* **Границы, области, Иссык-Куль, Токтогульское вдхр., ледники, города, вершины** — Natural Earth 1:10m (public domain).
* **Рельеф** — AWS Terrain Tiles (Mapzen Terrarium: SRTM/GMTED/ETOPO), z8 (~460 м). Из ЦМР построены: подложка, отмывка, 3D-модель, гипсография, статистика высот (`stats.json`).
* **Реки** — рассчитаны по ЦМР: заполнение понижений (priority-flood) → направления стока D8 → накопление стока; каждая река трассируется вверх/вниз от точки, лежащей на реке (город или гидропост). Гидросеть — водотоки с водосбором > 600 км².
* **Хребты** — линия максимальных высот поперёк приблизительной оси хребта (динамическое программирование по ЦМР).
* **Сон-Куль, Чатыр-Куль** — водная гладь, выращенная по плоской поверхности ЦМР.
* **Климат** — NOAA GHCN-Daily, 14 станций; нормы рассчитаны `scripts/climate_normals.py` (температура 1991–2020 или 1961–1990, осадки 1961–1990, только месяцы с полным рядом). Период и число лет показаны под каждым графиком.
* **Высотные пояса и карта лесов** — *учебные модели*: классификация ЦМР по границам поясов; для лесов — пояс × районы по литературе × экспозиция склона. В интерфейсе подписаны как схема/модель.
* Справочные значения (высоты вершин, площадь и глубина Иссык-Куля, длины рек, площади областей) подписаны как «справочно» и вынесены в `/sources`.
* Изображения — только реальные фотографии природы Кыргызстана. Каталог: `src/data/images.ts` (65 мест: сюжет, место, категория). Источник для каждого места: локальный файл `public/photos/…` (если добавлен и проверен) или Wikimedia Commons — браузер посетителя ищет фото через открытый API Commons (`src/lib/commons.ts`) и принимает только JPEG-фотографии со свободной лицензией (CC0 / CC BY / CC BY-SA / PD), которые по названию, описанию или категориям Commons относятся к нужному объекту в Кыргызстане; карты, схемы, зоопарки и NC/ND-лицензии отбрасываются. Автор, лицензия и ссылка на оригинал берутся из метаданных файла и показываются в подписи, лайтбоксе и на странице «Источники». Результаты кэшируются в localStorage на 7 дней. Конкретный файл можно закрепить полем `file` в `commonsSpecs`. Без интернета вместо фото показывается спокойный тёмный фон (без иконок и надписей).

Пересборка геоданных (нужны Python 3, numpy, pillow, shapely):

```bash
python3 scripts/build_gis.py <каталог natural-earth-geojson> <каталог тайлов terrarium z8> src/data/maps
```

## Лекция №5–6

Файл «ЛЕК 5-6_Растит. покров. Леса-в2.docx» **не был приложен к репозиторию**. Модули 5–6 написаны по опубликованной литературе (Головкова 1990; Атлас КиргССР 1987; Красная книга КР 2006) и включают все требуемые темы и виды (арча зеравшанская/туркестанская/полушаровидная, ель Шренка, пихта Семёнова, орех, яблоня Сиверса, груша, алыча, миндаль, тополя, ивы, берёзы, клёны). Тексты сосредоточены в `src/data/lessons/vegetation.ts` и `forests.ts` — их нужно сверить с лекцией (высотные диапазоны, списки растений).
