# Фотографии курса

Если локального файла нет, сайт ищет для места реальную фотографию в Wikimedia Commons (см. `commonsSpecs` в `src/data/images.ts` и `src/lib/commons.ts`). Таблица ниже — сюжеты всех мест: по ней можно закрепить лучший снимок (`file: 'File:…jpg'` в `commonsSpecs`) или положить собственный файл в `public/photos/`.

## Список мест

Сгенерировано командой `npm run photos:list` из `src/data/images.ts`.

**Общие требования:** реальная фотография, снятая в Кыргызстане (для видовых фото растений допустим природный ареал, но с честным указанием места); открытая лицензия (CC0, CC BY, CC BY-SA, Unsplash/Pexels License); без водяных знаков, рамок и надписей; ширина оригинала не меньше указанной; JPEG/PNG без сильной обработки. Для каждого фото нужны автор, ссылка на страницу оригинала и название лицензии.

**Как добавить:** `python3 scripts/prepare_photos.py original.jpg <id>` → в `images.ts` заполнить `photographer`, `source`, `sourceUrl`, `license`, `licenseUrl`, `width`, `height`, `responsive: true`, `status: 'ready'` → `npm run photos:check`.
